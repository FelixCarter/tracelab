To use; download the main folder and add it to your Matlab path. Then, point t_preproc to the folder containing your CSV files output from Trace. Output from t_preproc is used as input to subsequent functions. 

Documentation for each function will be coming soon - in the meantime, please see https://www.mdpi.com/1099-4300/28/5/503 for a high-level overview of the main functions. Each function contains some comments in the source code that describes input parameters.
